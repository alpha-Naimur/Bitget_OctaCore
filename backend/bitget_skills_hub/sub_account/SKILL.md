# Sub-Account Operations Skill

Bitget dedicated Agentic Sub-Account isolation, fund management, permission diagnostics, and internal zero-fee asset transfers.

## Tools
- `get_sub_account_status()`: Checks agent sub-account health and API permissions.
- `toggle_uid_privacy()`: Toggles UID privacy masking for screen sharing.
- `transfer_sub_account_funds(from_type, to_type, amount_usdt)`: Moves funds between Spot and Futures zero-fee.
